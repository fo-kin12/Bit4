# 🎵 BIT4 - Catálogo de Vinilos

> Página web responsive y moderna para una tienda de vinilos musicales (*"Vinilos que inspiran"*), desarrollada con **HTML5**, **Bootstrap 5** y una paleta de colores personalizada basada en **variables CSS (`:root`)** con modo oscuro y estética neón.

---

## 🎨 Paleta de Colores & Diseño

El proyecto implementa un diseño *Dark Mode* con efectos de iluminación y gradientes definidos en el archivo mediante variables CSS:

* **Fondo Principal (`--bg-primary`):** `#060b1e` (Azul medianoche profundo).
* **Tarjetas y Contenedores (`--bg-card`):** `#0e1738` (Azul marino para tarjetas de productos).
* **Acentos Neón (`--accent-cyan`):** `#00d2ff` (Iluminación, branding y detalles destacados).
* **Gradiente Activo y de Compra (`--active-gradient`):** Gradiente dinámico de Violeta (`#7b2cbf`) a Cyan (`#00d2ff`).
* **Textos Principales / Secundarios:** Blanco (`#ffffff`) y Gris Azulado (`#8a99ad`).

---

## 🛠️ Tecnologías Utilizadas

* **HTML5** (Estructura web semántica).
* **Bootstrap 5.3.2** (Framework CSS para grillas responsivas, componentes y utilidades).
* **Bootstrap Icons** (Iconografía vectorial para el carrito de compras, buscador y reloj).
* **CSS3 Custom Properties** (Gestión centralizada de estilos y paleta de colores).
